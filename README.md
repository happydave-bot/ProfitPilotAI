# ProfitPilotAI

ProfitPilotAI is a decision-support tool for Amazon → eBay product arbitrage.

## v0.1 scope
- Product input
- Product matching
- Profit calculation
- Deal decision
- Dashboard foundation

## Structure
- `core/` — business logic
- `connectors/` — market data integrations
- `ui/` — user interface
- `tests/` — automated tests
- `config/` — configuration
- `docs/` — project documentation

## Status
Early development — v0.1 foundation.
