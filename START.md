# ProfitPilotAI starten

1. PowerShell im Projektordner öffnen.
2. `git pull` ausführen.
3. `py -m pytest tests -v` ausführen.
4. `py main.py` starten.

Die aktuelle Oberfläche ist ein lokaler Prototyp. Für echte Amazon-/eBay-Daten müssen die entsprechenden API-Zugangsdaten später konfiguriert werden.
